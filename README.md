# Crazy Pencil Loader ✏️

A smooth, purely CSS and SVG-animated "Crazy Pencil Loader" built with modern web technologies. This project features a rotating pencil drawing and erasing loop animation designed for loading screens or placeholder states.

## 🚀 Features

* **Pure CSS & SVG:** No external JavaScript libraries required for the animation.
* **Scalable Vector Graphics (SVG):** Crisp graphics at any screen resolution.
* **Responsive Styling:** Built with CSS custom properties (`--hue`, `--bg`, `--fg`) and responsive font sizes.
* **Smooth Keyframe Animations:** Complex coordinated rotations, strokes, and eraser skew effects.

## 🛠️ Built With

* **HTML5**
* **CSS3** (Animations, Custom Properties, Grid Layout)
* **SVG** (Paths, ClipPaths, Groups)
